# 项目开发记录

## 2026-04-01

### 已完成 - v1.1 核心功能迭代

根据系统设计 v1.1.md，完成了以下核心功能的开发和迭代：

#### 1. Phase 1.1: Prompt 工程化

**新增模块**: `topstar/src/core/prompt/`

- ✅ **PromptAssembler.ts**: 六层 Prompt 组装引擎
  - L1 SOUL.md: 基础身份加载（只读缓存）
  - L2 IDENTITY.md: 身份标识加载（TTL缓存）
  - L3 USER.md: 用户画像加载（实时更新）
  - L4 TOOLS: 工具定义动态生成
  - L5 SKILLS: 技能清单动态生成
  - L6 RUNTIME: 运行时上下文生成
  - Prompt 压缩策略（summarize/truncate/hybrid）
  - Token 估算（中文1.5x，英文/4）

- ✅ **默认配置工厂**: `createDefaultConfig()`

#### 2. Phase 1.2: 意图识别基础

**新增模块**: `topstar/src/core/intent/`

- ✅ **IntentRouter.ts**: 意图路由引擎
  - 双层识别架构（网关层 + Skill层）
  - 6个内置核心意图：
    - `skill_invoke`: 调用特定 Skill
    - `memory_query`: 查询历史记忆
    - `code_request`: 代码生成/审查
    - `chit_chat`: 闲聊对话
    - `system_cmd`: 系统命令
    - `escalate`: 转人工/复杂任务
  - 置信度评估（高>0.8，中0.5-0.8，低<0.5）
  - INTENT.md 解析支持
  - 快速/完整双模式

- ✅ **IntentUtils.ts**: 意图识别工具函数
  - 相似度计算（Levenshtein、Jaccard、余弦）
  - 关键词提取
  - 实体提取（email、url、phone、date等）
  - 槽位提取

#### 3. Phase 1.3: 上下文增强

**新增模块**: `topstar/src/core/session/`

- ✅ **SessionSnapshot.ts**: 会话快照管理器
  - 创建快照（每10轮对话或Heartbeat）
  - 加载和恢复快照
  - 对话摘要生成
  - 关键实体提取
  - 待办任务识别

- ✅ **ContextManager.ts**: 上下文管理器
  - 跨会话意图继承（context_carry）
  - TTL 过期管理
  - 状态合并

- ✅ **ModelRouter.ts**: 模型路由配置
  - 意图-模型映射
  - 每日配额管理
  - 使用统计
  - 回退机制

### 技术实现要点

#### Prompt 组装流程
```
会话启动
    ↓
读取 SOUL.md (L1) → IDENTITY.md (L2) → USER.md (L3)
    ↓
生成 TOOLS (L4) → SKILLS (L5) → RUNTIME (L6)
    ↓
组装完整 Prompt → Token 检查 → 必要时压缩
    ↓
返回 AssembledPrompt
```

#### 意图识别流程
```
用户消息
    ↓
网关层规则匹配（正则/关键词）
    ↓ (置信度<0.8)
Skill 层语义匹配
    ↓
提取槽位值
    ↓
模型路由选择
    ↓
执行对应动作
```

### 接口定义

#### Prompt 组装
```typescript
interface AssembledPrompt {
  version: string;
  content: string;
  tokenCount: number;
  layers: { [key: string]: boolean };
}

async function assemble(
  agentId: string, 
  runtimeContext: RuntimeContext
): Promise<AssembledPrompt>;
```

#### 意图识别
```typescript
interface IntentRecognition {
  intent_id: string;
  confidence: number;
  matched_skill?: string;
  slots: Record<string, any>;
  routing: {
    target: 'main_session' | 'skill' | 'sub_agent' | 'acp';
    model?: string;
    priority: number;
  };
}

async function recognize(
  message: string,
  sessionContext: SessionContext
): Promise<IntentRecognition>;
```
