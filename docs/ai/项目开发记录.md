### 技术要点

#### 安装流程

```
用户请求
    ↓
Install Channel Router (解析安装指令)
    ↓
Package Downloader (获取包)
    ↓
Signature Verifier (校验签名)
    ↓
Dependency Resolver (解析依赖树)
    ↓
Sandbox (创建隔离环境)
    ↓
SkillRegistry (注册到数据库)
    ↓
SkillRuntime (热加载激活)
```

#### 权限模型

```yaml
permissions:
  - id: "network.fetch"
    scope:
      allow: ["https://api.example.com/*"]
      deny: ["127.0.0.1", "10.0.0.0/8"]
  
  - id: "fs.read"
    scope: ["${SKILL_PATH}/assets/*"]
  
  - id: "memory.write"
    scope: ["skill_state"]
    retention: "7d"
```

#### 状态流转

```
installed → active → disabled
   ↑          ↓        ↓
   └────── upgrading ──┘
   
active → unloaded (资源回收)
```
