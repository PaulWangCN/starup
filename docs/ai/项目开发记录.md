### 技术要点

#### 安装流程

```
用户请求
    ↓
Install Channel Router (解析安装指令)
    ↓
Package Downloader (获取包)
    ↓
Signature Verifier (校验签名)
    ↓
Dependency Resolver (解析依赖树)
    ↓
Sandbox (创建隔离环境)
    ↓
SkillRegistry (注册到数据库)
    ↓
SkillRuntime (热加载激活)
```

#### 权限模型

```yaml
permissions:
  - id: "network.fetch"
    scope:
      allow: ["https://api.example.com/*"]
      deny: ["127.0.0.1", "10.0.0.0/8"]
  
  - id: "fs.read"
    scope: ["${SKILL_PATH}/assets/*"]
  
  - id: "memory.write"
    scope: ["skill_state"]
    retention: "7d"
```

#### 状态流转

```
installed → active → disabled
   ↑          ↓        ↓
   └────── upgrading ──┘
   
active → unloaded (资源回收)
```

### 技术要点

#### Meta-Skill 执行流程

```
用户: "安装天气插件"
    ↓
IntentRouter: 识别为 skill.install (置信度 0.85)
    ↓
core.installer 执行槽位填充：
  - skill_hint: "天气" (模糊)
  - 调用 core.registry.search("天气")
    ↓
返回候选列表：
  1. weather-query (官方)
  2. weather-china (国内版)
  3. weather-pro (高级版)
    ↓
Agent 向用户确认："找到以下天气相关功能，请确认安装哪一个？"
    ↓
用户选择 → 下载 manifest → 权限预览 → 确认 → 执行安装
    ↓
SkillRuntime.loadAndActivate() → 热加载 → 更新 L5 层
    ↓
返回结果："已成功安装 weather-query@v2.1.0"
```

#### 安装事务流程

```
开始事务 TX
  ↓
下载包 → 验证签名 ✓
  ↓
解析依赖 → 发现冲突 ✗
  ↓
触发回滚：
  - 删除已下载的临时文件
  - 释放已获取的依赖锁
  - 报告错误给用户
```

#### Meta-Skill 权限模型

```yaml
# core.installer 特权
permissions:
  - id: "fs.write"
    scope: ["./.starup/skills/*", "./.starup/db/*"]
  - id: "skill.runtime.manage"
    scope: ["load", "unload", "reload"]
  - id: "prompt.layer.modify"
    scope: ["L5"]
  - id: "intent.router.register"
    scope: ["dynamic"]
```

## v1.3.1 SkillHub 集成修复记录

### 修复目标

修复 v1.3 中存在的以下问题：
1. SkillHub 来源错误（使用了虚构的 hub.startup.ai）
2. AI 回复中引用 `claw` 命令，与实际项目不符
3. 需要接入腾讯 SkillHub CLI 作为主要的 Skill 来源

### 修复内容

#### 1. Hub 来源更新

**文件**: `app/src/core/skills/SkillHubClient.ts`

将默认 Hub 配置从虚构的 `hub.startup.ai` 改为：
- **主要来源**: 腾讯 SkillHub (https://skillhub.tencent.com/)
- **兜底来源**: ClawHub (https://clawhub.ai/)
- **本地目录**: file://./.starup/hub

#### 2. AI 回复修复

**文件**: `app/src/cli/TerminalChat.ts`

更新 SOUL.md 模板：
```diff
- '2. **安装命令格式**：`claw install <skill-name>`',
+ '2. **安装命令格式**：`skillhub install <skill-name>` 或 `startup skill install <skill-name>`',
```

**文件**: `app/src/core/tools/ToolRegistry.ts`

修复工具安装提示：
```diff
- installCommand: 'claw install search',
- message: '...运行 "claw install search" 安装...',
+ installCommand: 'skillhub install search',
+ message: '...运行 "skillhub install search" 或 "startup skill install search" 安装...',
```

#### 3. CLI 帮助文档更新

**文件**: `app/src/cli/commands.ts`

更新 help() 输出，添加：
- External CLI (skillhub) 说明
- Hub Sources 优先级说明
- 移除 `claw` 命令引用

#### 4. SkillHub CLI 集成

**新增文件**: `app/src/core/skills/SkillhubCLI.ts`

封装腾讯 SkillHub CLI 调用：
- `isInstalled()`: 检查 CLI 是否已安装
- `search(query)`: 调用 `skillhub search`
- `install(skillId)`: 调用 `skillhub install`
- `getInstallGuide()`: 返回安装指南

#### 5. Meta-Skill 集成

**文件**: `app/src/core/skills/MetaInstallerSkill.ts`

修改安装流程，优先使用 SkillHub CLI：
1. 检查 `skillhub` CLI 是否已安装
2. 如果已安装，使用 `skillhub install <skill>`
3. 如果未安装，回退到内部 InstallManager
4. 如果安装失败且 CLI 未安装，提示用户安装 SkillHub CLI

**文件**: `app/src/core/skills/MetaRegistrySkill.ts`

修改搜索流程，优先使用 SkillHub CLI：
1. 尝试使用 `skillhub search` 搜索
2. 如果 CLI 未安装或无结果，使用 HTTP API 搜索
