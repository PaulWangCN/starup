# startup 系统 PRD - v1.1

## 1. 产品概述

### 1.1 版本说明

本版本（v1.1）在v1.0基础架构上，引入**主会话Prompt工程化体系**与**分层意图识别引擎**，实现从"功能可用"到"智能可调度"的跃迁。

### 1.2 新增核心能力

- **动态Prompt组装**：基于SOUL/IDENTITY/USER三层人格化配置，运行时动态构建系统提示词
- **分层意图识别**：网关层快速分类 + Skill层精细解析的双层识别架构  
- **Prompt版本控制**：主会话提示词快照与灰度发布机制
- **上下文感知路由**：基于意图置信度的多模型动态调度

---

## 2. 目标用户与场景（更新）

### 2.1 新增目标用户

- **AI产品经理**：需要精细控制AI人格与回复风格的运营人员
- **多模型调度者**：希望根据任务类型自动切换GPT-4/Claude/DeepSeek等模型的成本优化用户

### 2.2 新增核心场景

1. **人格化客服**：基于USER.md画像提供差异化的服务语调（正式/亲切/技术型）
2. **智能模型路由**：代码任务→DeepSeek-Coder，创意任务→Claude，闲聊→轻量模型
3. **上下文复活**：通过Session Snapshot实现"断点续传"式的长周期对话恢复

## 3. 功能需求

### 3.1 主会话Prompt系统（Main Session Prompting）

#### 3.1.1 六层Prompt架构

主会话系统提示词由以下六层按优先级堆叠组装：

| 层级 | 文件/来源 | 用途 | 热更新 |
|------|----------|------|--------|
| L1 基础身份 | `SOUL.md` | 核心人格、价值观、行为准则 | 需重启 |
| L2 身份标识 | `IDENTITY.md` | 名称、表情符号、版本号 | 实时 |
| L3 用户画像 | `USER.md` | 用户偏好、历史记忆摘要 | 实时 |
| L4 工具定义 | `TOOLS.md` | 可用工具JSON Schema定义 | Skill重载时 |
| L5 技能清单 | `SKILLS.md` | 当前加载的Skill目录与触发条件 | Skill变更时 |
| L6 运行时上下文 | 内存生成 | 当前时间、活跃会话数、系统状态 | 每次请求 |

#### 3.1.2 Project Context注入规范

主会话启动时自动读取工作区Markdown文件，按以下规则注入：

$$$
// 系统提示词模板结构
---
## 人格配置
{{SOUL.md content}}

## 身份定义  
{{IDENTITY.md content}}

## 用户画像
{{USER.md content}}

## 可用工具
{{TOOLS.md JSON Schema}}

## 已加载技能
{{SKILLS.md skill list}}

## 运行时上下文
- Current Time: {{ISO8601}}
- Session ID: {{session_id}}
- Channel: {{channel_type}}
- Model: {{model_name}}
---

**核心指令**: 你是{{identity.name}}，一个{{soul.description}}。请基于上述上下文处理用户请求。
$$$

#### 3.1.3 Prompt动态压缩策略

- **触发阈值**：当六层Prompt总token数超过8k时启动压缩
- **压缩优先级**：
  1. 保留L1-L3（人格层完整保留）
  2. 压缩L4（仅保留高频工具定义）
  3. 截断L5（仅保留触发概率高的Skill）
  4. 精简L6（移除非关键运行时指标）

### 3.2 意图识别系统（Intent Recognition）

#### 3.2.1 双层识别架构

采用"网关层粗分 + Skill层细分"的双层架构：
用户消息
↓
┌─────────────────┐
│  网关层识别器    │  ← 轻量模型/规则引擎，延迟<50ms
│  Intent Router  │
└────────┬────────┘
↓
分发至Skill或
直接响应
↓
┌─────────────────┐
│  Skill层解析器   │  ← 领域特定规则/向量检索
│  Slot Filling   │
└────────┬────────┘
↓
执行具体动作
plain
复制

#### 3.2.2 网关层意图分类

内置核心意图类型（IntentType）：

| 意图ID | 描述 | 路由策略 | 示例触发词 |
|--------|------|----------|------------|
| `skill_invoke` | 调用特定Skill | 路由至对应Skill | "生成图片"、"查天气" |
| `memory_query` | 查询历史记忆 | 主会话处理 | "还记得"、"之前说过" |
| `code_request` | 代码生成/审查 | 路由至ACP会话 | "写个函数"、"Review代码" |
| `chit_chat` | 闲聊对话 | 主会话直接响应 | "你好"、"今天怎么样" |
| `system_cmd` | 系统命令 | 主会话特权处理 | "/reset"、"/compact" |
| `escalate` | 转人工/复杂任务 | 创建子代理 | "帮我做一个完整的项目" |

#### 3.2.3 Skill层意图注册规范

每个Skill通过`INTENT.md`声明可识别的子意图：

$$$yaml
# intents/email-assistant/INTENT.md
intents:
  - id: "send_email"
    description: "发送邮件"
    examples:
      - "给张三发邮件"
      - "通知团队明天开会"
    slots:
      - name: "recipient"
        type: "string"
        required: true
        extractor: "llm"  # 或 "regex"
      - name: "subject"
        type: "string"
        required: false
        default: "无主题"
  
  - id: "query_inbox"
    description: "查询收件箱"
    examples:
      - "查看未读邮件"
      - "最近有什么邮件"
$$$

#### 3.2.4 置信度与回退机制

- **高置信度**（>0.8）：直接执行对应动作
- **中置信度**（0.5-0.8）：向用户确认意图："你是想X还是Y？"
- **低置信度**（<0.5）：回退至主会话通用处理能力，标记为`unknown`

### 3.3 上下文管理增强

#### 3.3.1 Session Snapshot机制

- **自动快照**：每10轮对话或Heartbeat时生成会话快照
- **快照内容**：压缩后的对话摘要 + 关键实体状态 + 待办事项
- **恢复策略**：用户重新连接时，先加载快照再追加新消息

#### 3.3.2 跨会话意图继承

支持通过`context_carry`标记实现意图跨会话延续：

$$$json
{
  "intent": "travel_booking",
  "slots": {"destination": "东京"},
  "context_carry": true,
  "ttl": 3600
}
$$$

## 4. 非功能需求

### 4.1 Prompt安全

- **注入防护**：对用户输入进行`<user_input>`标签包裹，与系统指令隔离
- **敏感词过滤**：在L3（USER.md）加载时扫描潜在Prompt Injection模式
- **权限分级**：
  - L1-L2：只读，仅管理员可修改
  - L3：用户自助维护
  - L4-L6：系统生成，不可手动编辑

### 4.2 性能指标（新增）

| 指标 | 目标值 | 说明 |
|------|--------|------|
| Prompt组装延迟 | <100ms | 六层Prompt读取与模板渲染 |
| 意图识别延迟 | <50ms | 网关层分类（轻量模型） |
| 上下文压缩耗时 | <200ms | 基于关键信息提取的摘要生成 |

## 7. 接口定义示例

### 7.1 Prompt配置接口

$$$typescript
// Prompt层级配置
interface PromptLayerConfig {
  version: string;           // 版本控制
  layers: {
    soul: {
      path: string;          // SOUL.md路径
      hash: string;          // 内容校验
      readonly: boolean;
    };
    identity: {
      path: string;
      cache_ttl: number;     // 缓存秒数
    };
    user_profile: {
      path: string;
      auto_update: boolean;  // 是否允许运行时更新
    };
  };
  compression: {
    threshold: number;       // token阈值，默认8000
    strategy: 'summarize' | 'truncate' | 'hybrid';
  };
}

// 运行时Prompt获取
async function assemblePrompt(
  agentId: string, 
  runtimeContext: RuntimeContext
): Promise<AssembledPrompt>;
$$$

### 7.2 意图识别接口

$$$typescript
// 网关层识别结果
interface IntentRecognition {
  intent_id: string;         // 如 "skill_invoke"
  confidence: number;        // 0-1
  matched_skill?: string;    // 目标Skill ID
  slots: Record<string, any>;
  routing: {
    target: 'main_session' | 'skill' | 'sub_agent' | 'acp';
    model?: string;          // 如 "deepseek-chat"
    priority: number;
  };
  fallback_action?: 'ask_clarify' | 'general_chat';
}

// 识别请求
async function recognizeIntent(
  message: string,
  sessionContext: SessionContext,
  options?: {
    fast_mode?: boolean;     // true=仅规则匹配，false=LLM增强
    allowed_intents?: string[]; // 白名单过滤
  }
): Promise<IntentRecognition>;
$$$

### 7.3 Skill意图注册

$$$yaml
# skill.yaml 扩展字段
intent_recognition:
  primary_model: "deepseek-chat"  # 用于本Skill意图识别的模型
  fallback_patterns:              # 兜底正则规则
    - pattern: "(查|查询).{0,5}(天气|气温)"
      intent: "query_weather"
      confidence_boost: 0.3
  
  context_retention:              # 上下文保持策略
    max_turns: 5                  # 多轮对话保持轮数
    slot_carry_over: true         # 槽位值跨轮继承
$$$

## 8. 风险与对策（新增）

| 风险 | 影响 | 对策 |
|------|------|------|
| Prompt注入攻击 | 高 | 用户输入标签隔离 + SOUL.md只读保护 |
| 意图识别冷启动 | 中 | 内置100+常见意图的预训练向量 |
| 多模型路由成本失控 | 中 | 意图-模型映射表 + 每日调用配额限制 |
| Prompt版本冲突 | 低 | 版本哈希校验 + 灰度发布机制 |

### 9.2 术语表（新增）

- **Prompt Layer**: 系统提示词的六个堆叠层级（L1-L6）
- **Intent Router**: 网关层意图分发器
- **Slot Filling**: 从消息中提取参数槽位值的过程
- **Context Carry**: 意图状态跨会话保持机制
- **Session Snapshot**: 会话上下文的序列化快照
