# 目录管理 PRD
本项目下直接有两个目录，外部涉及一个目录

## 目录说明
### 源代码目录
topstar是源代码的根目录

### PRD目录
docs是prd文件目录，下面有两个目录：
- human
human目录是人类创建的PRD文件目录，人类自己维护，里面的各个文件要求都必须实现，AI可以阅读，绝对不允许进行编辑和删除
- ai
ai自动生成的PRD文件，在这个目录下ai可以自己维护各种PRD文件，注意只能放PRD文件

### 工作目录
~/.starup是 topstar agent 的工作空间，生成的内容、下载和创建的skills等agent能力生成文件都应该放在这里，必须包含以下文件和目录：
- memory
与用户沟通的当天对话记录摘要，文件名为：yyyy-MM-dd.md，内容样例：
```markdown
# yyyy-MM-dd memory log

## {对话主题1}
{对话内容摘要}

---

## {对话主题2}
{对话内容摘要}

---

...
```
这个需要AI理解并每天定时生成

- skills
AI通过对话后下载和创建的skills都需要放在这个目录下。

## 管理原则
1. 必须使用git进行starup目录的文件管理，方便回退和改动管控
2. ai进行编程、生成文件等改动后必须删除失效、无效的代码和文件，防止文件和代码无限膨胀
3. python项目需要创建.venv虚拟环境，在虚拟环境中运行

## AI使用权限
- 允许：阅读
- 禁止：编辑、删除
